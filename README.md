# NISO Technology Portal

The official landing page and digital hub for NISO Technology. This repository hosts a modern, lightweight, high-performance web interface designed to showcase our core operational pillars: autonomous intelligence, custom-engineered algorithms, and professional digital art curation.

## 🌐 Core Pillars Featured:
* **Autonomous AI Agents:** Deploying specialized, logic-driven models to automate complex operations.
* **Algorithmic Logic:** High-stability systems engineered for real-time data processing and execution.
* **NISO Art Gallery:** High-fidelity digital art production, advanced upscaling, and creative tech presentation.

## 🛠️ Tech Stack:
* **Semantic HTML5 & CSS3:** (Custom Variables, Grid & Flexbox)
* **Vanilla JavaScript:** For minimalist, high-performance interactivity.
* **Optimized:** Built for lightning-fast loading speeds and mobile-first responsiveness.

## 🚀 How to Run:

Since this is a visual-first, vanilla implementation, there are no complex dependencies or build steps.

### 1. Direct Open
Simply locate the `index.html` file in your file explorer and open it with any modern web browser (Chrome, Firefox, Safari, Edge).

### 2. Local Development Server (Recommended)
For the best experience with all features (like smooth scrolling and animations), run a simple local server.

**Using Python:**
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using Node.js (npx):**
```bash
npx serve .
```
Then visit the URL provided in your terminal.
